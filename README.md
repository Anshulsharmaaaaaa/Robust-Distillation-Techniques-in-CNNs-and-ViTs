# Robust-Distillation-Techniques-in-CNNs-and-ViTs
Developed a PyTorch-based project on robust knowledge distillation in CNNs and Vision Transformers (ViTs). Implemented logit, feature, and consistency-based distillation, including CNN-to-ViT and ViT-to-CNN transfer. Evaluated accuracy, robustness under noise, model size, and efficiency using CIFAR-10.
